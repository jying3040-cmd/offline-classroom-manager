# REQUIREMENTS.md — 需求与业务说明

> 本文回答：这个产品**要做什么**、业务规则是什么。
> 实现方式（数据库表、音频管线、构建流程）见 `ARCHITECTURE.md`。

## 1. 项目背景

### 为什么做这个项目

小学语文教师的课堂里有一批高频、重复、又必须即时完成的操作：点谁回答问题、表扬谁、听写哪一课的词、这周谁的红花最多。这些事如果靠纸笔或通用软件做，要么记不住，要么操作太重，课上一打断节奏就接不回来。

本项目把这些操作收进一个**打开就能用、不需要网络、不需要登录**的桌面应用里。

### 要解决什么问题

| 问题 | 本项目的应对 |
|---|---|
| 点名/抽人靠印象，学生觉得不公平 | 抽签结果在动画开始前由加密级随机确定，动画只是展示 |
| 表扬记录靠脑子，期末说不清 | 小红花流水账只增不改，随时可查每条加减的原因明细 |
| 听写要老师一个个读词 | 输入词语自动生成标准普通话发音，按遍数与间隔自动播放 |
| 教室网络不稳定，云服务用不了 | 全部离线：教材词表发音随包分发（213 个 wav） |
| 学校电脑不方便装软件 | 绿色免安装，解压即用；数据存在本机 |
| 家长/学校担心数据外泄 | 不注册、不上传、数据不出本机 |
| 期末统计手工做 | 一键导出 Excel 报表（明细 + 汇总排行） |
| 换电脑或重装会丢数据 | U盘备份/恢复，整包迁移 |

### 目标用户

- **主要用户**：小学语文教师（个人使用，非多教师协同）。
- **次要用户**：使用同一台教室电脑的其他任课教师（各自独立使用，不共享数据）。
- **使用环境**：教师办公电脑、教室一体机（希沃等），常以投影形式面向全班。

### 设计取向

面向**教室投影**设计：大字号、高对比度、卡通配色（奶油底 + 粗描边贴纸卡片 + 糖果色），保证后排学生看得清。

## 2. 用户角色

| 角色 | 能力 |
|---|---|
| 教师（唯一角色） | 全部功能；无权限分级、无账号体系 |

**没有管理员、没有学生账号、没有家长端。** 学生只是被管理的数据对象，不参与任何交互。

## 3. 功能模块

### M1 名单管理

- 多班级创建与切换，显示各班人数。
- 学生卡片网格展示；添加、编辑、删除（带确认）。
- 批量导入：按换行或中英文逗号分隔，**自动去重**。
- 学生字段：姓名、学号、性别、小组名称、组员号（后两项可选）。组员号须为正整数，可留空或清空；卡片显示“xx小组 · xx号组员”。
- 学生卡片同步显示红花角标。

### M2 小红花

- **授奖页（两段式加减制）**：每张卡片两个圆形按钮「−」「＋」，点击后先弹原因确认（数量 1/2/3/5 + 六个快捷原因标签 + 自定义输入），**确认才写入**。
- 「⋯」菜单：查看该学生的加减原因明细，**每条记录可单独删除（带确认）**，关闭后合计实时刷新。
- **榜单**：本周（周一起）/ 本月 / 累计，前三名奖牌标记。
- **今日**：奖励朵数 / 人次 / 扣减统计卡 + 全天流水时间线。

### M3 随机抽签

- **公平性**：结果在动画开始前由加密级随机确定，滚动动画只是展示，杜绝「能被操作」的观感。
- **一轮不重复**（默认开启）：本轮抽过的学生自动排除，抽完自动重置开新一轮；可一键重置。
- **人数**：1~5 人（多槽位滚动依次停定）。
- **范围**：全班 / 男生 / 女生，可再按小组、组员号组合筛选（取交集）；选项来自当前班级实际信息。仅选组员号可抽取各小组同号组员。切换班级后清空小组和组员号筛选，未设置字段的学生仍可参与不限定该字段的抽签。空范围不能抽签，一轮不重复继续按学生记录。
- **结果页**：超大字号（单人 96px）+ 弹出动画，专为白板投影设计；支持「再抽一次」。
- **历史**：每次抽签记录可查，名字冗余存储，学生改名或删除后历史仍可读。

### M4 单词听写

- **单入口「输入词语」**：粘贴词语（一行一词，支持 `word,释义`，分号分隔也可），自动生成标准普通话发音。
- **一键导入教材词表**：按课文批量建组，发音随包分发，无需联网。
- **播放流程**：播放 →（每词遍数 1/2/3）→ 作答间隔（5/10/15/20 秒，可暂停续秒）→ 下一题 → 对答案页。
- **播放控制**：暂停 / 继续 / 重读本词 / 重读上一题 / 跳过。
- **关键约束**：**播放界面只显示题号，绝不显示单词。**
- **入库**：音频复制进应用数据目录统一命名，单元归属记入数据库；先复制后写库，断电不脏库。

### M5 报表、备份与交付

- **Excel 报表**：红花页头部导出按钮 → 今日 / 本周 / 本月 → 生成两个工作表（明细 + 汇总排行）保存到桌面，可一键打开所在文件夹。
- **U盘备份/恢复**：设置页检测可移动磁盘（失败可手输路径）→ 备份前关闭数据库确保落盘 → zip 包含数据库 + 全部录音 → 恢复时清空重建 + 路径校验 → 完成后自动拉起新实例重启。
- **交付打包**：生成解压即用的发布包与一页纸使用说明。

## 4. 核心业务流程

### 一堂课的典型使用

```text
打开应用
    ↓
选择班级（名单页）
    ↓
上课提问 → 抽签页抽 1~3 人（大字展示）
    ↓
表现好 → 小红花页点「＋」→ 选数量与原因 → 确认
    ↓
听写环节 → 听写页粘贴本课词语 → 生成发音 → 开始播放
    ↓
下课 → 小红花「今日」查看全天流水
    ↓
期末/月末 → 设置页导出 Excel 报表
```

### 小红花记账

```text
点击卡片「＋」或「−」
    ↓
弹出原因确认（数量 1/2/3/5 + 快捷原因 + 自定义）
    ↓
确认 → 写入一条流水记录
    ↓
合计与榜单实时刷新
```

纠错方式：插入一条反向记录（指向原记录），而不是修改或删除原记录。

### 听写准备

```text
粘贴词语（或一键导入教材词表）
    ↓
合成标准普通话发音（全程离线）
    ↓
音频复制进应用数据目录，统一命名并解析时长
    ↓
写入数据库（先复制后写库）
    ↓
生成听写单元，进入播放
```

### 备份与恢复

```text
设置页 → 检测可移动磁盘（或手输路径）
    ↓
关闭数据库（确保落盘）
    ↓
打包数据库 + 全部录音为 zip
    ↓
恢复时：校验路径 → 清空重建 → 解包
    ↓
自动拉起新实例重启
```

## 5. 业务规则

### 名单

1. 批量导入时按换行或中英文逗号分隔，重复姓名自动去重。
2. 删除学生需二次确认。
3. 班级和学生均支持归档标记（软删除语义），历史记录不会因删除而断裂。

### 小红花

4. **流水账只增不改**：扣减与纠错一律通过插入反向记录实现，原始记录保留。
5. 每条流水记录可单独删除（带确认），删除后合计实时刷新。
6. 榜单统计口径：本周以**周一起**计算；另有本月与累计。
7. 榜单前三名带奖牌标记。
8. 每条加减记录必须能追溯到数量与原因。

### 抽签

9. 抽签结果必须在动画开始前确定，动画不得影响结果。
10. 默认开启「一轮不重复」：本轮已抽中的学生不再被抽中，抽完自动开启新一轮。
11. 支持一键重置本轮已抽记录。
12. 抽签历史中的姓名**冗余存储**，学生改名或删除后历史仍可读。
13. 抽取人数范围 1~5 人；范围可选全班 / 男生 / 女生。

### 听写

14. **播放界面只显示题号，不显示单词**——这是听写有效性的前提。
15. 每词可设置遍数（1/2/3）与作答间隔（5/10/15/20 秒）。
16. 作答间隔可暂停并续秒。
17. 支持暂停、继续、重读本词、重读上一题、跳过。
18. 音频必须**先复制入库再写数据库记录**，避免断电产生脏数据。
19. 教材词表发音随安装包分发，**不依赖网络**。

### 数据与备份

20. 所有数据保存在本机 `%APPDATA%\classroom_manager\data\`，**每台设备独立**。
21. 备份必须同时包含数据库与全部录音；只备份数据库会导致听写功能失效。
22. 备份前必须关闭数据库，确保数据落盘。
23. 恢复必须做路径校验（防 zip-slip），并清空重建后再解包。
24. 不注册账号、不上传任何数据。

## 6. 状态与边界

### 功能状态

| 能力 | 状态 |
|---|---|
| M1 名单管理 | 已交付并验证 |
| M2 小红花 | 已交付并验证 |
| M3 随机抽签 | 已交付并验证 |
| M4 单词听写 | 已交付并验证 |
| M5 报表 / 备份 / 交付打包 | 已交付并验证 |
| 分小组抽取 | **未实现**（需先在名单中增加分组字段） |
| 导入录音（微信录音导入向导） | **已下线**，入口移除 |

### 异常场景

| 场景 | 行为 |
|---|---|
| 空班级 / 无学生 | 页面不报错，显示空状态 |
| 学生全部已抽完 | 自动开启新一轮 |
| 待抽范围内无人 | 提示并保持可用 |
| 粘贴的词语格式异常 | 按行解析，无法识别的行跳过 |
| 发音合成失败 | 提示失败，不写入半成品记录 |
| 检测不到可移动磁盘 | 允许手动输入路径 |
| 恢复包路径非法 | 拒绝解包，保护现有数据 |
| 断电解中断导入 | 先复制后写库，数据库不产生脏记录 |

### 边界与限制

- 单机使用，**不支持多设备同步**（换机靠 U盘备份/恢复）。
- 不支持多教师协同、不支持学生端。
- 不接入任何网络服务。
- 听写音频为 Windows 系统语音合成，音色固定，不支持自定义音色。
- 界面语言仅中文。

### 数据约束

- 数据库与录音文件均位于 `%APPDATA%\classroom_manager\data\`。
- 音频文件在应用数据目录中统一命名，单元归属记在数据库中。
- 删除学生不影响已产生的流水与抽签历史（姓名冗余存储）。

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| 离线 | 全部功能离线可用，教材词表发音随包分发 |
| 隐私 | 数据不出本机；不注册、不上传、无遥测 |
| 性能 | 页面切换与卡片操作即时响应；抽签动画流畅 |
| 可用性 | 绿色免安装，解压即用；面向投影的大字号与高对比度 |
| 兼容性 | Windows 64 位；可在教室一体机上运行 |
| 可维护性 | 纯 Dart 依赖，唯一原生代码为 runner 内置播放器；避免原生插件对「开发人员模式」的依赖 |
| 可移植性 | 数据库 + 录音整包即可迁移到另一台电脑 |
| 数据安全 | 备份含全部数据；恢复前校验路径；备份前关闭数据库 |

## 8. 验收标准

### M1 名单

1. 新建班级、班级切换、人数统计正确。
2. 学生卡片网格展示正常；添加/编辑/删除（含确认）可用。
3. 批量导入支持换行与中英文逗号分隔，重复姓名自动去重。

### M2 小红花

4. 卡片「＋／−」点击后弹出原因确认，确认才写入；取消不产生记录。
5. 流水只增不改；扣减通过反向记录实现，原始记录仍可查。
6. 单条流水可删除，删除后合计实时刷新。
7. 本周（周一起）/ 本月 / 累计榜单数值正确，前三名带奖牌。
8. 「今日」统计与全天时间线一致。

### M3 抽签

9. 抽签结果与动画展示一致，且结果在动画前已确定。
10. 开启「一轮不重复」时，本轮内不重复抽中同一学生；抽完自动重置。
11. 支持 1~5 人抽取，范围可选全班/男生/女生。
12. 结果页在投影上清晰可读；「再抽一次」可用。
13. 抽签历史可查，且在学生改名或删除后仍可读。

### M4 听写

14. 粘贴词语后可生成发音；「一键导入教材词表」在**断网**状态下可用。
15. 播放流程符合设定：遍数 → 作答间隔 → 下一题 → 对答案页。
16. 作答间隔可暂停并续秒；暂停/继续/重读/跳过均可用。
17. **播放界面不出现单词文本。**
18. 音频先入库后写库；中断不产生脏数据。

### M5 报表、备份与交付

19. 可导出今日/本周/本月报表，含明细与汇总排行两个工作表，并能打开所在文件夹。
20. 备份包包含数据库与全部录音；恢复到另一台电脑后听写功能仍可用。
21. 恢复时非法路径被拒绝，现有数据不被破坏。
22. 恢复完成后应用自动重启并正常加载数据。
23. 发布包解压到任意目录后可独立运行（自包含）。
